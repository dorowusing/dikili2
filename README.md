# 📖 Dikili — Aplikasi & Korpus Digital Naskah Klasik Gorontalo (Naskah D)

[![GitHub Pages Ready](https://img.shields.io/badge/GitHub%20Pages-Ready-brightgreen?logo=github)](https://dorowusing.github.io/dikili2/)
[![Manuskrip](https://img.shields.io/badge/Manuskrip-Naskah%20D%20(Mustapa%20Taha)-amber)](file:///content/dikili2/curation/naskah_d_kurasi_lengkap.md)
[![Korpus](https://img.shields.io/badge/Korpus-17%20Sair%20%7C%2096%20Unit-blue)](file:///content/dikili2/curation/naskah_d_complete.json)
[![Lisensi](https://img.shields.io/badge/Kajian-Filologi%20Kritis%20IAIN%20Gorontalo-teal)](#kajian-filologi--peneliti)

**Dikili** adalah aplikasi pembacaan digital *mobile-first* sekaligus repositori dataset terstruktur untuk naskah sastra keagamaan klasik tradisi Maulid masyarakat Gorontalo, secara khusus bersumber dari **Naskah D** (Koleksi Mustapa Taha, Desa Bakti Pulubala & Batu Layar, Gorontalo).

Aplikasi ini dibangun murni menggunakan **HTML5, CSS3, dan Vanilla JavaScript modern** tanpa dependensi pihak ketiga (*zero dependencies*), sehingga dapat dijalankan secara langsung, di-hosting di GitHub Pages, maupun diakses luring (*offline*).

---

## 🌟 Fitur Utama Aplikasi Dikili

1. **Antarmuka Mobile-First yang Responsif**:
   - Didesain khusus untuk kenyamanan membaca di perangkat genggam (*smartphone*), tablet, maupun layar desktop.
2. **Navigasi 17 Bab Sair Lengkap**:
   - Menelusuri bab demi bab syair secara terstruktur, mulai dari **Sair 1 (a)** (*Untaian Salam & Pujian Agung*) hingga **Sair 17 (q)** (*Qasidah Penutup & Doa Khatam*).
3. **Sorotan Refrein Zikir Sakral (*Jābu*)**:
   - Kartu khusus berornamen bingkai emas untuk menandai refrein zikir sakral lokal yang dilantunkan bersahut-sahutan dalam upacara tradisi Dikili.
4. **Teks Hikayat Bahasa Gorontalo Asli (Arab Pegon)**:
   - Kartu beraksen hijau zamrud (*emerald*) untuk menampilkan alih aksara teks prosa berbahasa Gorontalo klasik dari aksara Arab Pegon (seperti kisah Siti Halimah as-Sa'diyyah dan peristiwa pembelahan dada Nabi).
5. **Filter Layer Pembacaan Dinamis**:
   - Pembaca dapat bebas menampilkan atau menyembunyikan layer: **Teks Arab**, **Transliterasi Latin**, **Terjemahan Indonesia**, atau **Teks Gorontalo**.
6. **Kenyamanan & Personalisasi Membaca**:
   - Pengatur ukuran teks Arab (`A-` / `A+`).
   - Tiga pilihan tema visual: **Naskah Kuno/Perkamen** (*Parchment*), **Mode Gelap** (*Dark/Malam*), dan **Mode Terang** (*Light/Putih*).
   - Penanda bait tersimpan (*Bookmarks*) dengan penyimpanan lokal (*LocalStorage*).
   - Mesin pencarian instan kata kunci di seluruh 17 Sair dan 96 unit teks.
   - Fitur salin teks bait ke papan klip (*clipboard*) dengan satu sentuhan.

## 🏛️ Kajian Filologi & Kodikologi Naskah D

Dasar kurasi naskah mengacu pada penelitian filologi kritis:
- **Judul Penelitian**: *"Kearifan Lokal dalam Naskah Dikili"* (2015)
- **Peneliti**: Dr. Ayuba Pantu, M.Pd & Dr. H. Muh. Arif, M.Ag (IAIN Sultan Amai Gorontalo)
- **Koleksi / Pemilik Naskah**: Mustapa Taha
- **Asal Naskah**: Desa Bakti Pulubala dan Desa Batu Layar, Gorontalo
- **Fisik Naskah**: 188 halaman (185 halaman disunting), ukuran 20 x 14 cm
- **Kolofon**: Disalin pada 1419 H / 1999 M (Batu Layar) dan 1424 H / 2003 M (Bakti Pulubala)
- **Karakteristik**: Naskah D dipilih para filolog sebagai naskah landasan (*base text*) karena paling lengkap, memiliki variasi *jābu* terbanyak, dan memuat prosa berbahasa Gorontalo beraksara Arab Pegon.

## 🚀 Cara Menjalankan Aplikasi

### 1. Langsung Melalui Browser (Tanpa Instalasi)
Cukup buka berkas `index.html` langsung di browser mana pun (bahkan via protokol `file:///`), aplikasi langsung berjalan penuh dengan seluruh 96 unit bait dan zikir tanpa memerlukan server eksternal.

### 2. Mengaktifkan GitHub Pages (Hosting Gratis)
1. Buka halaman repositori di GitHub: `https://github.com/dorowusing/dikili2`.
2. Masuk ke menu **Settings** ➔ **Pages**.
3. Pada bagian **Build and deployment** ➔ **Source**, pilih opsi **Deploy from a branch**.
4. Pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1-2 menit, aplikasi Anda akan otomatis mengudara di:
   🔗 **`https://dorowusing.github.io/dikili2/`**

### 3. Menjalankan via Server Lokal (Opsional)
Jika ingin menjalankan web server lokal berbasis Python:
```bash
python3 -m http.server 8000
```
Lalu buka alamat `http://localhost:8000` di peramban Anda.
